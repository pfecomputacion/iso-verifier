2 · Preparar el entorno virtual

Desde Git Bash, en la carpeta del proyecto:

cd ~/Documents/Iso_Verifier
source .venv/Scripts/activate     # si ya tienes el venv

Si no tienes el venv creado todavía:

python -m venv .venv
source .venv/Scripts/activate
python -m pip install --upgrade pip
python -m pip install -r requirements-dev.txt

Si te falta algo, instala manualmente:

python -m pip install PySide6 python-gnupg Pillow requests pyinstaller debx

3 · Generar los iconos

python generate_icon.py

Deberías ver:

  · assets/icon.png
  · assets/icon_256.png
  · assets/icon.ico

✅ Iconos generados en ./assets/
ℹ️ Nota Si no ejecutas este paso, el .exe saldrá con el icono por defecto de Python y el .deb sin icono.

4 · Compilar todo

python build_installers.py

Esto hace tres cosas en orden:

Paso A · PyInstaller → genera el ejecutable base

dist/iso-verifier.exe           (Windows)
dist/iso-verifier               (Linux, sin extensión)

Paso B · debx → genera el paquete Debian

dist/iso-verifier_1.5.0_amd64.deb

Paso C · Inno Setup → genera el instalador de Windows

dist/iso-verifier_setup.exe

5 · Resultado final

En la carpeta dist/ tendrás:

ArchivoPlataformaUso

iso-verifier_setup.exe Windows Instalador con accesos directos, menú inicio, etc.
iso-verifier_1.5.0_amd64.deb Linux (Debian/Ubuntu) Paquete instalable con dpkg -i

6 · Verificar los artefactos

Probar el .exe "pelado"

./dist/iso-verifier.exe

Se abre la app directamente, sin instalación.

Probar el instalador .exe

Doble clic en dist/iso-verifier_setup.exe. Se abre el asistente de Inno Setup:

  1. Elegir carpeta de instalación.
  2. Crear accesos directos.
  3. Instalar.
  4. Ejecutar desde el menú inicio o escritorio.

Probar el .deb en Linux

Copia el .deb a un Linux (Debian/Ubuntu) y allí:

sudo dpkg -i iso-verifier_1.5.0_amd64.deb
sudo apt-get install -f    # por si faltan dependencias
iso-verifier               # ejecutar

7 · Generar un .deb funcional en Linux

🚨 Aviso importante El .deb que generas desde Windows con debx contiene el binario de Windows, no el de Linux. Es un contenedor .deb válido, pero al ejecutarlo en Linux fallará con Exec format error.

Opción A · Compilar en Linux (recomendado)

Lleva el código (sin .venv/, dist/, build/) a un Linux y allí:

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
python generate_icon.py
python build_installers.py

Esto genera un .deb con binario Linux, que sí funciona.

Opción B · Usar WSL

Desde Windows, con WSL instalado:

wsl -e bash -c "
  cd /mnt/c/Users/Recepción/Documents/Iso_Verifier &&
  python3 -m venv .venv-linux &&
  source .venv-linux/bin/activate &&
  pip install -r requirements-dev.txt &&
  python generate_icon.py &&
  python build_installers.py
"

Genera un .deb real para Linux sin salir de tu Windows.

8 · Limpiar y recompilar

rm -rf dist/ build/
python build_installers.py

O simplemente ejecuta python build_installers.py de nuevo: el script ya limpia dist/ y build/ al inicio.
